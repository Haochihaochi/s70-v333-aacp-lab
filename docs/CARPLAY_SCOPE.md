# Apple CarPlay scope

“AACP” is commonly used to mean both Apple CarPlay and Android Auto. This foundation currently implements only the Android Auto receiver track.

Open Headunit is an Android Auto receiver. It does not make the IHU a native Apple CarPlay receiver. The X50 community solution also generally used an Android Auto receiver for no-dongle Android Auto and a separate AutoKit/Carlinkit path for CarPlay.

No CarPlay binary, authentication material, MFi credential or proprietary AutoKit component is included here. A future CarPlay track must have a clear licence, lawful authentication model and independent safety review.
